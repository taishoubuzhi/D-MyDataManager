# 自动标签（规则 + 模型）`auto_tag`

给条目自动挂标签：**规则 + 模型**两套标签一起算，合并去重后挂上去。

* 规则那侧用共享库的规则集（就是 `auto_tag.rule` 用的 `.configs/autolabel.rules.json`）：页面上的「规则」卡
  可以直接新建 / 编辑 / 删除规则（含提示词规则「交模型判断」），提示词规则给的「补充要求」会拼进模型提示词；
* 模型那侧按数据类型对齐模型，整批请求交给模型工具库（`dm_plugin.lib.model.api.run_batch()`），带进度与取消；
* 合并开关 `merge_rule_tags`（默认**打开**）：打开 = 规则标签 ∪ 模型标签（去重后受上下限约束，上下限按合并后的集合算），
  关掉 = 只挂模型的标签；
* 两边给出的、标签库里还没有的名字，**挂之前先建进标签库**（`runner.ensure_tags()`）。

插件 `auto_tag.rule` 与 `auto_tag` 在清单里互指 `conflicts`（用户 m42668）：**都能载入，但不能同时启用**。

* `builtin: false`：作为外部插件交付，默认**不启用**（`enabled: false`），需要时在「插件」页打开；卸载不影响程序本体。
* 依赖 `lib.autolabel`（对齐表与批量管线）、`lib.model`（可选：跑模型与下载权重）、`builtin.lib.ui`（界面工具库）。

## 三个入口

| 位置 | 按钮 | 行为 |
| --- | --- | --- |
| 侧边栏「自动标签」页 | 开始挂标签 / 预览（不写库） | 完整流程：规则命中 + 对齐表 → 批量请求 → 合并 → 写库，带进度与取消 |
| 数据管理页工具栏 | 自动挂标签 | **后台直接**给选中条目挂标签（不跳页），完成后提示并刷新列表 |
| 条目右键菜单 | 自动挂标签 | 同上，只处理这一条 |

## 页面上有什么

* **规则卡**：规则表（名称 / 类型 / 匹配 / 要挂的标签 / 状态）+ 新建 / 编辑 / 删除 / 恢复出厂；
  与 `auto_tag.rule` 共用同一份规则文件（`.configs/autolabel.rules.json`），在哪个插件里改都一样；
* **数据类型对齐表**：5 列 = 数据类型 / 方案 / 主模型 / 对齐模型 / 状态；「方案」列三态 = `启用`（跟随系统）/
  `自定义`（自己挑过）/ `已停用`（这一行被关掉）；「主模型 / 对齐模型」两列显示**登记时的名字**
  （没登记才写「未登记：<方案 key>」）；保存后会自动选中刚改的那一行，备注显示在表格下面那行提示里。
  工具栏：「设置对齐（编辑框里勾「启用系统方案」就跟随系统）/ 一键补全 / 检查缺失 / 重置 / 全部重置 / 打开模型页」。
* **运行区**：最少 / 最多几个标签（`min_tags` / `max_tags`，上限还会被库里现有标签总数压住）、
  进度条 + 取消 + 结果预览。
* 设置存在用户清单 `.configs/autolabel.align.json`：每个用途下**全部数据类型一行**，写全量；刷新时表格直接读清单。

## 对齐模型（先读一遍，再交给主模型）

* 图片走 **图像描述**（系统方案配 BLIP）：`plugin.lib.autolabel.pipeline.ALIGN_TASKS = {"IMAGE": "caption", "AUDIO": "asr"}`，
  结果作为「对齐信息」拼进主模型提示词（截断 1200 字）。
* 音频走**语音识别**（Whisper Base）；视频与文本类配的是**向量模型**（CLIP / all-MiniLM），只出向量、不参与提示词，
  运行日志里会说明「只出向量、不参与提示词」；视频抽帧需要额外解码器，当下不生成文字描述。
* 对齐模型没登记 / 条目文件不在盘上 / 单条失败都不会挡住主流程，但会经 `on_problem` 写进日志。

## 新标签会自动入库

`runner.ensure_tags()` 在写库前先调一次 `app.sdk.items.ensure_tags(names)`，把**规则与模型两边**给出的、
标签库里还没有的标签建进标签库，再按标签分组 `tag_items()`（用户 m42577 / m42753：可以自由发挥，
不该因为标签不存在而挂不上）。建标签失败只记一条 warning，不影响挂标签本身。

## 文件表

| 文件 | 作用 |
| --- | --- |
| `plugin.json` | 清单：三个选项（`min_tags` / `max_tags` / `merge_rule_tags`）、`conflicts: ["auto_tag.rule"]`、依赖 `lib.autolabel` / `lib.model`(可选) / `builtin.lib.ui` |
| `runner.py` | 纯逻辑：选项、规则命中、对齐与模型计划、合并、新标签入库、写库（不碰界面/数据库） |
| `plugin.py` | 接线：注册页面 + 管理页工具栏 / 条目菜单两个入口（后台线程 + 队列 + 主线程轮询） |
| `ui/page.py` | 页面：规则卡 + 对齐表 + 一键补全 / 检查 / 重置 + 运行区 |

复用的控件（进度面板、规则编辑器、对齐编辑器）在共享库 `plugins/lib.autolabel/.plugin/ui/controls.py`，本插件不重复实现。

## 边界

* 只通过 `app.sdk` 访问数据（`items.*` 读写、`models.*` 跑模型、`ui.open_page` 跳页）；
* 界面代码只 import 集成界面工具库（`dm_plugin.builtin.lib.ui`）与 PyQt6 布局、`qfluentwidgets.FluentIcon`，
  由自检 `autolabel_ui_via_tool_library` 兜底；
* 单条失败不影响整批：失败的请求与写不进去的标签都会在结果里列出来；**绝不静默下载权重**（下载统一交给模型页队列，需用户确认）。
