# 自动标签（模型）`auto_tag`

任务 3 的交付物：给条目自动挂标签，**规则**与**模型**两套方案共用同一个页面，
与任务 2 的 `auto_tag.rule` **冲突**（两个清单互指 `conflicts`）：两者都能载入，
但不能同时启用——同时启用时按载入顺序靠前者胜出，另一个保持禁用。

* `builtin: false`：作为外部插件交付，默认**不启用**（`enabled: false`），
  需要时在「插件」页打开；卸载本插件不影响程序本体。
* 不调用模型时它完全离线：只按规则匹配；调用模型时全部请求都走
  `app.sdk.models.run_batch()`，由模型工具库决定并发与排队。

## 四个入口

| 位置 | 按钮 | 行为 |
| --- | --- | --- |
| 侧边栏「自动标签」页 | 开始挂标签 / 预览（不写库） | 完整方案：规则或模型，带进度与取消 |
| 导入页 | 按规则预填标签 | 导入前还没有条目 id，只能按规则把标签填进标签框 |
| 数据管理页工具栏 | 自动挂标签 | 给选中条目按规则**立刻**挂一批，然后提示去页面跑模型 |
| 条目右键菜单 | 自动挂标签 | 同上，只处理这一条 |

## 页面上有什么

* 顶部切「规则（不调用模型） / 模型（按数据类型）」，下面是两套视图：
  * **规则视图**：规则表（复用共享库的规则编辑器），规则集就是任务 2 的那一份；
  * **模型视图**：数据类型 ↔ 模型对齐表（标签模型 + 对齐模型，如 IMAGE 用 CLIP；5 列 = 数据类型 / 方案 / 主模型 / 对齐模型 / 状态，
  每行都是这个数据类型自己的设置、可以各不相同；方案列 = 启用 / 自定义 / 已停用，状态按这一行的主模型与对齐模型有没有登记说清楚缺哪个；
  保存后会自动选中刚改的那一行，备注显示在表格下面的提示里）、
    「设置对齐（编辑框里勾「启用系统方案」即跟随系统）/ 一键补全 / 检查缺失 / 重置 / 全部重置 / 打开模型页」；
* 运行区：要不要合并规则标签（`merge_rule_tags`）、最少/最多几个标签
  （`min_tags` / `max_tags`，上限还会被库里现有标签总数压住）、
  进度条 + 取消 + 结果预览。

「一键补全」先 `models.create_from_template(key)` 把这一行还缺的模型登记成草稿并写回对齐表；缺权重时弹**一个**确认框，
确认后用 `models.download_model()` 把主模型与对齐模型的权重交给模型页那套下载队列（镜像回退 / 续传 / 可取消）。
「检查缺失」对已登记模型跑 `models.requirements()` 说清还缺什么。**不确认就不会下载，运行环境只能在模型页装**。

## 规则从哪来

规则集与对齐表都在共享库 `lib.autolabel`：

* 出厂规则 `plugins/lib.autolabel/data/rules.json`（25 条）；
* 用户规则 `.configs/autolabel.rules.json`（只存与出厂不同的部分）；
* 数据类型对齐 `.configs/autolabel.align.json`。

任务 2 与任务 3 读的是**同一份**用户规则文件，所以两套方案的结果可以直接合并
（`docs/AUTOLABEL_PLAN.md` 偏差 #11）。两个插件的规则字段、算子完全一致：

* `match`：结构化的字段匹配（后缀/名称/路径/类型/正文），命中就挂标签；
* `prompt`：提示词规则，命中的条目会把它自己的标签与提示词一起交给模型
  （3.6：两种 `kind` 都支持，`prompt` 规则也参与合并）。

## 文件表

| 文件 | 作用 |
| --- | --- |
| `plugin.json` | 清单：三个选项、依赖 `lib.autolabel` / `lib.model`(可选) / `builtin.lib.ui` |
| `runner.py` | 纯逻辑：选项、正文读取、规则标签、模型计划、合并、写库（不碰界面/数据库） |
| `plugin.py` | 接线：注册页面 + 三个扩展点入口 |
| `ui/page.py` | 页面：两套方案 + 对齐表（含只读系统方案列）+ 套用/重置/一键补全 + 运行区 |

复用的控件（进度面板、规则编辑器、对齐编辑器）在共享库
`plugins/lib.autolabel/ui/controls.py` 里，本插件不重复实现。

## 边界

* 只通过 `app.sdk` 访问数据（`items.*` 读写、`models.*` 跑模型、`ui.open_page` 跳页）；
* 界面代码只 import 集成界面工具库（`dm_plugin.builtin.lib.ui`）与 PyQt6 布局、
  `qfluentwidgets.FluentIcon`，由自检 `autolabel_ui_via_tool_library` 兜底；
* 单条失败不影响整批：失败的请求与写不进去的标签都会在结果里列出来。
