# 自动关键词（`auto_keyword`）

用模型给条目生成关键词：按**数据类型**对齐模型，整批请求交给模型工具库批处理，
带进度与取消。

## 入口

| 入口 | 位置 | 行为 |
|---|---|---|
| 「自动关键词」页 | 导航栏（`plugin.auto_keyword`，排序 162） | 配对齐表（含只读系统方案列）、套用方案 / 重置 / 一键补全（缺权重只问一次后下载）、整批生成关键词（有进度与取消） |
| 「自动生成关键词」 | 数据管理页工具栏 | 跳到「自动关键词」页并提示（选中了几个条目会说清楚） |
| 「自动生成关键词」 | 数据管理页条目右键菜单 | 同上（会说清楚是哪个文件） |

导入页没有入口：关键词没法靠本地规则离线生成，而导入前条目还没入库、没有 id，
构造不出 `BatchRequest`。

## 页面内容

* **数据类型对齐**：每个数据类型一行（5 列：`数据类型 / 方案 / 主模型 / 对齐模型 / 状态`；「方案」列写 `启用`（跟随系统）/ `自定义`（自己挑过）/ `已停用`（这一行被关掉）
  ——跟随系统就是「启用」，自己挑过就是「自定义」），
  「设置对齐」开共享库的 `AlignDialog`（`purpose="keyword"`），「重置」把这一行还原成系统方案、「全部重置」还原整张表；
  选中的行下面会写清楚它实际调哪个模型。
* **跟随系统方案**：`lib.autolabel/.data/align.json` 给每种数据类型都配好了模型（轻量优先），对齐表的「方案」列显示这一行是
  `启用`（跟随系统）还是 `自定义`。选中一行点「设置对齐」，在编辑框里勾上「启用系统方案」就让这一行**跟随系统**（`AlignRow.use_preset`：模型与对齐模型都用出厂值，
  出厂换模型它跟着换；要在编辑框里取消勾选「启用系统方案」才能自己挑模型与对齐模型，下拉里 `已登记` 组不会再重复列出系统方案已有的同一个模型）。
  「一键补全」把这一行还缺的模型逐条 `models.create_from_template(key)` 登记成**草稿**并写回对齐表；缺**模型文件**时弹**一个**确认框
  （按「权重 / 配置 / 分词器」分组列出缺哪些），确认后 `models.download_model()` 把它们交给模型页那套下载队列（不确认不下载）；
  「检查缺失」对已登记的模型跑 `models.requirements()`，运行环境仍然只在「模型」页装。
* **运行**：「开始生成关键词」「预览（不写库）」「刷新」；
  只对对齐表里配了（且已登记）模型的数据类型发请求，跳过的条目在预览框里逐条说明。

## 与标签插件的关系

* 关键词与标签是两套数据：本插件与 `auto_tag` / `auto_tag.rule`
  **都不互斥**，可以同时启用。
* 复用共享库 `lib.autolabel` 的**对齐表文件**
  `.configs/autolabel.align.json`：里面 `label` 段给标签用、`keyword` 段给关键词用，
  两个用途各存各的，互不干扰。
* 批处理管线也来自共享库（`pipeline.py`），只是 `purpose="keyword"`，
  提示词模板换成「挑关键词」。

## 选项

| key | 类型 | 默认 | 说明 |
|---|---|---|---|
| `min_keywords` | int（1–50） | 3 | 模型给得比这少就整条作废 |
| `max_keywords` | int（0–50） | 8 | 超出的按模型给的顺序截断；`0` = 不限（关键词没有「全集」上限） |

## 文件

| 文件 | 作用 |
|---|---|
| `plugin.json` | 清单：依赖共享库与界面工具库，默认不启用（外部插件） |
| `plugin.py` | 接线：注册页面 + 管理页两个入口 |
| `runner.py` | 纯逻辑：读选项、排请求、收结果、写库（不 import Qt） |
| `ui/page.py` | 页面（只用集成界面工具库与共享控件） |

## 边界

* 只读/写自己需要的数据：`app.sdk.items`（`list_items` / `add_keywords` / `notify_changed`）、
  `dm_plugin.lib.model.api`（`templates` / `create_from_template` / `requirements` / `page_route`）、
  `app.sdk.ui.open_page`；模型批量一律走共享库的 `pipeline.run()` → `models.run_batch()`。
* 界面只用集成界面工具库（`dm_plugin.builtin.lib.ui.plugin`）与共享控件
  （`dm_plugin.lib.autolabel.ui.controls`），图标用 `FluentIcon` 名字字符串。
* 不下载权重、不装运行环境：这些都在模型页做，这里只登记草稿并提示缺什么。
